# Fonts for the social image

`schibsted-grotesk-500.ttf` and `schibsted-grotesk-800.ttf` are static
instances (weights 500 and 800, Latin subset) of
[Schibsted Grotesk](https://github.com/schibsted/schibsted-grotesk), made with
fontTools from the variable font the site loads through `next/font`. The image
renderer behind `next/og` needs static TTF or OTF files.
